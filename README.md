# Classic Brick Game Clone

A native recreation of the classic handheld brick games, written from scratch in C++ using the Win32 API. This project brings back the retro nostalgia of grid-based monochrome LCD gaming with smooth performance and a double-buffered display to eliminate screen flickering.

Developed by **EugeneGtt**.

## 🎮 Included Games
* **Tetris:** The ultimate classic. Score points by clearing lines before the bricks hit the ceiling.
* **Snake Classic:** Eat the food pellets to grow. Features an optimized algorithm to prevent food from spawning under the snake and a true "YOU WIN!" condition if you manage to fill the entire grid.
* **Tank Battalion:** Battle enemy tanks across 10 unique, destructible levels. 
* **Pong Retro:** A 10-round arcade challenge against an AI bot that scales in difficulty.
* **Brick Breakout:** Break all the bricks across 3 geometric stages (Heart, Number 7, and Dumbbell) without losing your 3 lives.

## 🕹️ Controls
* `Arrow Keys` — Move / Rotate / Change Selection
* `ENTER` or `SPACE` — Start Game / Select / Action (Shoot)
* `ESC` — Return to Main Menu

## 🚀 Technical Features
* Built natively with **C++** and **Windows API (Win32)** (Not an emulator).
* Optimized **Double Buffering** rendering to ensure a stable, flicker-free screen.
* Custom implementation of retro LCD aesthetics using fixed-grid matrices ($10 \times 20$).
